# Product Documents

승인된 제품 정의와 개발 요구사항을 보관한다.

## Current baseline

현재 팀 전체가 가장 자주 확인해야 하는 승인 PRD는 저장소 루트의
`/Router_Security_Checker_PRD_v0.1.md`를 canonical baseline으로 사용한다.

루트에 두는 이유는 Researcher, Manager, Developer가 저장소 진입 직후 기준 문서를 바로 찾을 수 있게 하기 위해서다.

## Put here

- 다음 PRD 버전 초안 및 승인본
- Approved requirements
- Scope definition
- Version/MVP definition
- 제품 요구사항의 세부 보조 문서

새 PRD가 승인되면 Project Lead가 루트의 canonical PRD를 교체하고, 이전 버전은 이 폴더에 보존한다.

## Do not put here

- 아직 검증되지 않은 조사 결과
- Manager 감사 메모
- 구현 코드

조사 결과는 `../research/`, 감사 결과는 `../audit/`에 먼저 저장하고 승인된 내용만 제품 기준으로 승격한다.
